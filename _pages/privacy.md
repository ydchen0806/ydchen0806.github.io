# Privacy & Website Analytics

This personal academic website uses the existing **Flag Counter visitor map** and **Google Analytics** to understand general readership. These third-party services process visits according to their own policies.

If the optional private **Visitor Insights** service is enabled, it collects the visit time (UTC), viewed **page path without query parameters**, referrer **domain**, approximate country/region/city, browser family, device type, and network IP address. The IP address is masked by default in the dashboard. The site owner can view the unmasked IP for up to **3 days**; raw IPs are then deleted. Visit records are removed after **30 days**. These records are private and are not published on this website.

This optional tracker does not use cookies or browser fingerprinting. It respects Global Privacy Control (GPC) and Do Not Track (DNT) browser signals. You can opt out of this tracker in the same browser at [disable optional visitor tracking](/?visitor_optout=1), and re-enable it at [restore optional visitor tracking](/?visitor_optout=0). This opt-out does not control the separate Flag Counter or Google Analytics services.

Approximate geolocation is determined from the visitor's network connection; a city or IP address does not reliably identify an individual. For questions about this website's analytics or privacy, please contact [cyd0806@mail.ustc.edu.cn](mailto:cyd0806@mail.ustc.edu.cn).
